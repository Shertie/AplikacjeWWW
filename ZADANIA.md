## 2. Definicja modeli

✅ **Wykonano:**

### Model Category
```python
class Category(models.Model):
    name = models.CharField(max_length=200, unique=True)
    description = models.TextField(blank=True, default='')  # Dodane w zadaniu 3
    created_at = models.DateTimeField(auto_now_add=True)
```

### Model Topic
```python
class Topic(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    category = models.ForeignKey(Category, on_delete=models.CASCADE, related_name='topics')
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
```

## 3. Dodanie pola description do modelu Category

✅ **Wykonano:**
- Dodano pole `description` typu `TextField` do modelu `Category`
- Pole ma parametry: `blank=True, default=''`
- Utworzono migrację za pomocą `python manage.py makemigrations`
- Plik migracji: `posts/migrations/0002_category_description.py`

### Zawartość pliku migracji 0002_category_description.py:
```python
# Generated by Django 5.2.7 on 2025-10-10 09:39

from django.db import migrations, models


class Migration(migrations.Migration):

    dependencies = [
        ('posts', '0001_initial'),
    ]

    operations = [
        migrations.AddField(
            model_name='category',
            name='description',
            field=models.TextField(blank=True, default=''),
        ),
    ]
```

## 6. Instalacja i konfiguracja django-debug-toolbar

✅ **Wykonano:**

### Instalacja:
```bash
pip install django-debug-toolbar
```

### Konfiguracja w settings.py:

1. **Dodano do INSTALLED_APPS:**
```python
INSTALLED_APPS = [
    # ...
    'debug_toolbar',
    'posts',
]
```

2. **Dodano middleware:**
```python
MIDDLEWARE = [
    # ...
    'debug_toolbar.middleware.DebugToolbarMiddleware',
]
```

3. **Dodano INTERNAL_IPS:**
```python
INTERNAL_IPS = [
    '127.0.0.1',
]
```

### Konfiguracja w urls.py:
```python
from django.urls import path, include
from django.conf import settings

urlpatterns = [
    path('admin/', admin.site.urls),
]

if settings.DEBUG:
    urlpatterns = [
        path('__debug__/', include('debug_toolbar.urls')),
    ] + urlpatterns
```

### Migracje debug_toolbar:
```bash
python manage.py migrate

Wynik:
Applying debug_toolbar.0001_initial... OK
```

## 7. Testowanie operacji CRUD w panelu administracyjnym

✅ **Do wykonania przez użytkownika:**

Panel administracyjny jest dostępny pod adresem: http://127.0.0.1:8000/admin/

### Dane do logowania:
- **Username:** admin
- **Password:** [hasło ustawione podczas tworzenia superusera]

### Funkcje do przetestowania:

#### Category:
- **Dodawanie:** Kliknij "Add" przy Category, wypełnij pola `name` i `description`
- **Modyfikacja:** Kliknij na istniejącą kategorię i zmień dane
- **Usuwanie:** Zaznacz kategorię i wybierz "Delete selected categories"

#### Topic:
- **Dodawanie:** Kliknij "Add" przy Topic, wypełnij `title`, `content`, wybierz `category`
- **Modyfikacja:** Kliknij na istniejący temat i zmień dane
- **Usuwanie:** Zaznacz temat i wybierz "Delete selected topics"

### Django Debug Toolbar - co analizować:

**Panel po prawej stronie zawiera:**
1. **SQL:** Liczba i treść zapytań SQL wykonanych dla danej strony
2. **Time:** Czas renderowania strony i poszczególnych komponentów
3. **Request:** Informacje o żądaniu HTTP (GET/POST parametry, cookies, headers)
4. **Templates:** Użyte szablony i czas ich renderowania
5. **Cache:** Operacje na cache (jeśli skonfigurowane)
6. **Signals:** Sygnały Django wysłane podczas żądania
7. **Logging:** Logi wygenerowane podczas przetwarzania żądania

**Obserwacje podczas testowania:**
- Przy operacji **dodawania**: Zapytania INSERT do bazy
- Przy operacji **modyfikacji**: Zapytania SELECT (odczyt) i UPDATE
- Przy operacji **usuwania**: Zapytania DELETE
- Przy wyświetlaniu listy: Zapytania SELECT z JOIN (Topic → Category)
